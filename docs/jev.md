# Jev 判断器（1.2.0）

[返回首页](../README.md) · [命令行配置](cli.md)

Jev 是可选的辅助判断器，处理任务下发检查、工具调用检查、长工具结果筛选、学生交卷检查，以及按需选择 MCP 和 Skill。老师下发完整任务、学生独立解题、投票共享发现、交卷暂停与老师综合验收的原有流程保留；最终是否通过仍由老师决定。

自动上下文压缩本身无需 Jev。启用 Jev 并勾选“任务下发”时，它还可提示摘要应重点保留的证据、约束和待核验事项；压缩时机仍受本地容量预算控制，摘要由原成员模型生成。Jev 失败或关闭不会阻止自动压缩，也不能授权删除原文。

## 配置与使用

1. 点击“布置任务”框中“运行设置”右侧的“Jev设置”图标，填写专用接口地址和 Jev 密钥。Class 固定使用 TypeSafe System One 原生接口和 `jev-latest` 模型，无需选择接口类型或填写模型名称；默认地址为 `https://api.typesafe.ai/v1/systemone`。需要单独取得 TypeSafe API Key，Class 不会借用老师或学生的密钥。
2. 默认停用，课堂运行不会自动调用判断服务。左侧“启用”、右侧“停用”用于选择状态，选中侧显示阴影，点击“保存”后才生效。有已保存或新填写的密钥并选择“启用”后，显示“任务下发”“工具调用”“执行结果”“提交材料”四项，按需勾选；默认选择后两项。主动点击“测试连接”只发送固定测试内容，不保存设置或执行任务。
3. 填写新密钥并保存会替换旧密钥，之后的 Jev 调用使用新密钥；输入框留空则保留原来保存的密钥。从未配置密钥且输入框为空时，无论选择启用还是停用，点击“保存”都会提示“尚未配置Jev密钥”，弹窗保持打开，配置不变。初始默认停用不需要保存即可正常使用 Class。
4. 保存后启动新任务，Jev 直接按勾选环节处理；未勾选的上下文整理环节保持原样。启用 Jev 后，同时对按需搜索 MCP 和 Skill 提供选择建议，不需要新增勾选项。在“Jev设置”中可查看所选任务的请求数、回退次数、实际节省字符和累计判断耗时。选择“停用”并保存可恢复原流程，密钥和四项选择保留，便于再次启用。正在运行的任务保持启动时的设置，无需重新配置老师、学生或迁移历史数据。

密钥通过 Class 的独立凭据存储加密保存，配置展示和日志不应包含完整密钥。Windows 使用当前账户的系统加密能力；Linux 使用私有数据目录中的密钥与密文，目录和文件权限仍是其保护边界。不要把真实密钥写入源码、README 或分享的配置示例。

## 行为与限制

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 总开关 | 关闭 | 未启用时课堂不调用判断服务；手动连接测试除外 |
| 任务下发检查 | 关闭 | 保留完整任务与黑板，提示验证重点和相关材料引用 |
| 工具调用检查 | 关闭 | 识别疑似重复或偏离目标的调用，在结果中附加后续建议，不取消或放行操作 |
| 工具结果筛选 | 开启 | 总开关开启后，判断较长工具结果中哪些内容需要进入后续上下文 |
| 交卷检查 | 开启 | 总开关开启后，给老师附加交卷检查信息，不替老师宣布通过 |
| 扩展按需选择 | 跟随总开关 | `search_tools`、`search_skills` 查询时辅助排序已授权 MCP 和 Skill，独立于上述四项勾选 |
| 请求超时 | 1500 毫秒 | 限制等待辅助判断的时间 |
| 最大并发 | 2 | 限制同时发出的判断请求 |
| 长结果门槛 | 6000 字符 | 小结果不进入长结果筛选 |

精简只作用于已保存原文的长命令或网页结果；保留头尾，跳过失败结果、媒体、完整 JSON 和识别出的代码，并保护带有错误或核验标记的段落。内容识别不是所有语言的语义校验，分类仍可能出错。省略处附带证据引用，Agent 可以通过 `read_evidence` 补读。学生投票、老师接收的完整候选和全员证据不受筛选。实际耗时与费用还应计入 Jev 请求本身；“实际节省字符”记录成功应用的精简量，不等于节省的 token 或费用。

判断器会收到执行相应检查所需的任务或工具内容；自动判断只有在你启用并配置服务后才发送，手动连接测试仅发送固定测试内容。它不保证每次分类正确，也不能代替原有工具权限、运行检查或老师的最终验收。接口超时、不可用或返回无法识别的结果时，应保持 Class 原有工作流可继续。

扩展选择只提供有限长度的任务摘要、查询词，以及已授权条目的 ID、名称和说明；不发送 Skill 正文、MCP 地址、启动命令、环境变量、请求头或凭据。每次最多判断两批、每批12项，判断相关性、语义重复和优先少量加载或先查目录的策略。只有高置信度结果用于提示，语义重复不作为删除依据。未判断、低置信度或不优先的条目仍保留，成员可以通过搜索或显式ID使用已授权能力。

加载动作由 Class 执行：MCP 先连接并发现工具，需要时才真正调用；Skill 先搜索目录，再读取正文及所需资源。Jev 不能返回可执行安装命令、扩大授权或根据名称相同直接合并扩展。只有 Class 核对实际配置与适用授权后确认完全一致的条目才会合并显示；语义相似只是选择建议。连接失败、缺少工具和依赖准备的边界见 [扩展说明](extensions.md#按需准备与连接)。

这属于文本上下文管理，不是模型 KV Cache 交流。任务、工具和模型调用的真实效果仍需要通过隔离测试或实际使用验证。

旧配置中的生效模式会自动移除，已保存的启用状态、独立密钥与四项选择保留；原先开启但仅统计的配置，在新任务中会直接应用所选判断。旧任务记录保持原样，历史仅统计任务会标为“历史任务：仅统计，未应用判断”。

## 开发配置

配置中的 `judge` 对象使用以下字段；`protocol` 和 `model` 固定为 `system-one`、`jev-latest`，旧配置或请求中的其他取值会归一为这两个值。桌面版密钥通过界面独立保存。源码 CLI 可从 `CLASS_JEV_API_KEY` 环境变量读取独立密钥；若使用该变量，请省略配置中的 `apiKey` 字段（显式空值会覆盖环境变量）。示例只保留空值：

```json
{
  "judge": {
    "enabled": false,
    "protocol": "system-one",
    "baseUrl": "https://api.typesafe.ai/v1/systemone",
    "model": "jev-latest",
    "apiKey": "",
    "timeoutMs": 1500,
    "maxConcurrency": 2,
    "minOutputChars": 6000,
    "features": {
      "taskDispatch": false,
      "toolCalls": false,
      "toolResults": true,
      "submissionReview": true
    }
  }
}
```

发布前先在本地模拟判断服务中验证关闭、按项启用、旧配置兼容、超时和异常返回，使用独立临时数据目录。真实服务的连通性与判断质量应单独记录，不能用模拟服务通过替代。
