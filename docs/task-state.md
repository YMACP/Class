# 任务状态与安全续跑

Class 1.2.0 保留原有课堂流程：学生独立处理同一道完整任务，发现经讨论进入黑板，老师综合全员成果验收，未通过则继续当前任务。

- **自动上下文压缩**：接近工作窗口容量时，由该成员原本使用的模型整理旧轮次和过长历史，保留原任务、约束、验收条件、最新反馈及近期完整工具调用。摘要通过校验、完整原文成功归档且请求确实缩小后才替换上下文；摘要失败或取消时保留原文。无法安全容纳时保留会话并提示成员恢复，不静默丢弃要求。
- **原文按需读取**：摘要带有 `context_read` 引用，按字节分页读取压缩前的公开上下文；每个任务、每个成员独立，只读自己的档案，不依赖长期记忆开关。凭据、模型隐藏推理和媒体二进制不进入这类档案。工具证据仍通过 `read_evidence` 读取，历史会话检索 `session_search` 的原有权限与设置保持不变。工作摘要和压缩档案不等于已验证证据。
- **逐项验收**：老师先从完整任务中整理验收条件。最终提交必须逐项给出判断、理由和已有证据引用；需要工具验证的条件不能只凭文字声明通过。纯文字推导可以使用文字证据。最终判断仍由老师负责，系统检查引用和字段，不能替代事实核验。
- **增量记忆**：后台按来源引用及内容摘要分批整理长期记忆。每批记忆与处理进度一起提交，暂停、退出或失败后从未完成部分继续；长来源会分段处理。原有来源权限、清空/删除保护和 `session_search` 保留。
- **安全续跑**：新版任务的恢复点单独加密保存。停止或重启后，在历史任务中点击“继续任务”，恢复原任务、成员上下文、验收条件、计划/待办及证据。成员与模型配置需要匹配原任务；MCP/Skill 授权重新按当前配置检查。

恢复点不会重建原操作系统进程或浏览器页面。已确认的副作用有记录保护；中断时结果不确定的操作不会自动重放，老师必须用恢复后产生的只读证据核查，才能结束任务。远端 MCP 的取消不保证撤回已发生的操作。

旧版本历史任务没有恢复点，仍可查看和检索，但不能凭历史文字直接续跑。演示任务不生成恢复点。完成或删除任务时清理其恢复点；长期记忆索引不读取加密恢复点。

扩展配置、权限和运行边界见 [MCP 与 Skills](extensions.md)。

自动压缩不需要新增模型密钥或开启 Jev。启用 Jev 且勾选“任务下发”时，Jev 可提示摘要应重点保留的证据、约束和待核验项；不能删除原文或替代老师验收。校长同样可压缩自己的只读问答，仍基于提问时的冻结课堂快照。

上下文容量优先使用提供方明确配置的 `contextWindowTokens`，否则使用已有 1M 选项或本地 128000-token 工作窗口；这些是本地预算，不代表自动识别了远端模型容量。预算包括系统提示、工具声明和输出预留。网页搜索与分页抓取的字段和限制见 [工具说明](tools.md)。
