# Windows 使用指南

[返回首页](../README.md) · [模型配置](cli.md) · [工具能力](tools.md) · [记忆管理](memory.md)

本页介绍 Windows x64 和 ARM64 发布包；Linux 另见 [Linux 使用指南](linux.md)，目前不提供 macOS 发布包。程序使用现代浏览器显示界面；浏览器自动化工具支持已安装的 Edge、Chrome 或 Firefox。x64 目录选择组件使用 .NET Framework 4.x；ARM64 版需要 Windows 11 ARM64 和 .NET Framework 4.8.1（Windows 11 22H2 起内置）。Windows 11 ARM64 已通过本轮五套独立发布验收，见 [ARM64 说明](windows-arm64.md) 与 [验收记录](native-acceptance.md)。

浏览器工具默认优先查找 Edge/Chrome，未找到时查找 Firefox；特殊安装位置可通过 `CLASS_BROWSER_EXECUTABLE` 指定完整绝对路径。Firefox 需要 149 或更新版本，以保持下载禁用。Class 不内置或自动下载浏览器；本次适配不增加运行时依赖。缺少可用浏览器时会在调用 `browser` 工具时明确报错，不阻止其他任务。Agent 使用独立浏览器实例，不接管用于显示 Class 界面的日常浏览器；各浏览器共用原有暂停、恢复、取消和清理机制。

## 下载与首次运行

1. 从项目 Releases 下载与设备匹配的 `Class-1.0.0-windows-x64.zip` 或 `Class-1.0.0-windows-arm64.zip`，完整解压后双击 **Class.exe**，并保留随包的 `THIRD_PARTY_NOTICES.txt` 和 `README.txt`。用同次发布的 `SHA256SUMS-windows-x64.txt` 或 `SHA256SUMS-windows-arm64.txt` 核对下载文件；x64 另保留 `SHA256SUMS.txt`。无需安装 Node.js、Bun 或 npm。本地构建输出在源码同级的 `../class-releases/windows-<架构>/Class.exe`。
2. 程序在后台启动仅本机可访问的服务，并打开浏览器，无需保持命令行窗口。在界面中点击“退出服务”可停止程序。关闭浏览器标签页不会取消运行中的任务；再次双击 exe 会打开现有工作空间，不会重复启动服务。
3. 在 **教室管理** 中添加 **1 名老师和 2–16 名学生**，填写成员名称、接口模式、baseurl、apikey 和模型名称。每个成员可以独立选择 Messages、Responses 或 Chat，支持混合小组。新增成员默认 Messages，已有成员保留原协议，未设置协议的旧配置按 Chat 处理。成员模态框不再显示探索视角和 JSON 模式；编辑已有成员时保留其已有配置。
4. 根据接口模式填写 baseurl，再点击连接测试。Messages 自动追加 /v1/messages；Responses 和 Chat 保存时要求 baseurl 以 /v1 结尾，分别追加 /responses 和 /chat/completions。不要填写完整接口端点。
5. 在课堂填写任务，点击“运行设置”图标后，通过文件夹按钮直接打开 Windows 原生文件夹选择窗口，选定本地工作目录，并按需调整投票时限，保存后开始讨论。老师和学生默认均可在工作目录执行命令。
6. 点击“小组成员”“讨论日志”图标查看成员状态和进展。学生交卷触发可恢复暂停，老师综合全体学生已有成果审查；未通过时，黑板分别显示已核实事实、待解决项和建议，学生带上反馈继续同一次任务。最终通过后，点击“答案”图标查看综合答案与验收报告。黑板右上角文件夹图标可分页查询运行档案，工具长输出可继续翻页。无需模型的固定演示保留在命令行入口。

## 清除任务与本地数据

讨论进度中，日志图标左侧的红色垃圾桶可“清除任务”。确认后删除当前显示任务及其讨论记录、日志、答案、运行档案和依赖该来源的记忆；运行中的任务会先停止并等待工具退出，再完成删除。清除期间显示“清除中…”，完成后恢复待开始状态和 `00:00:00`，保留任务输入、成员及工作目录文件。若清除的是正在查看的历史任务，页面返回当前实际任务。记忆数据库暂不可用时，独立删除记录先阻止重新导入，原任务仍可清除；页面明确提示关联索引等待恢复后清理。

Agent 配置、Windows 账户加密的密钥、最近 50 次运行记录和持久记忆保存在 **%LOCALAPPDATA%\discussion**。最近运行列表的数量限制不删除已经归档到记忆库的会话；Agent 仍可按需检索，用户可从长期记忆的来源入口查看原文或删除对应会话。页面不会回传已保存的密钥；编辑时密钥留空会保留原值。更换 exe 不会丢失配置。加密凭据只适用于保存它的 Windows 账户。为兼容已有安装，Class 继续使用上述数据目录和加密格式，无需迁移配置。

## 更换数据目录

在 **讨论记录** 页面最下方，可以输入本地数据目录，或点击右侧文件夹按钮使用 Windows 原生目录选择窗口。本次更新的 x64 版提供两个操作：“迁移到空目录”复制当前成员配置、加密密钥、讨论记录、持久记忆及默认工作目录，原始数据保留；“加载已有目录”直接加载另一份已有配置和历史，不接受空目录，不复制或合并当前数据。迁移目标须为空目录或尚未创建的目录；已有内容不会被覆盖。独立设置的外部工作目录保持原位置。任务执行、连接测试或目录选择期间不能迁移或加载其他目录。

原数据目录不存在或无法访问时，会先显示恢复页面。“使用默认目录”可以加载默认目录已有数据，或在没有数据时初始化；“选择数据目录”可以加载移动后的完整 Class 数据目录，也可以选择用户已经创建的空目录，由 Class 自动初始化配置、工作目录、历史记录和记忆存储。所选目录必须已经存在；未知非空目录或残缺、损坏的 Class 数据目录会被拒绝。只有新目录成功启动后才会记住选择。选择目录不会删除原数据，也不能恢复已经被删除的文件。

工作目录中的普通只读文件和 Git 的 `.git/objects/pack` 打包文件可正常迁移，源文件保持不变，复制的工作文件保留只读属性。真实的权限限制或文件占用仍会明确报错。

成功迁移或加载后，Class 会记住新目录，再次从相同入口启动时继续使用。使用 --data-dir 或 CLASS_DATA_DIR / DISCUSSION_DATA_DIR 指定的启动位置各自保留独立选择。恢复记录保存在原数据目录之外，因此原目录不存在时仍能记住选择。新目录中的后续改动不会回写旧副本。

如果数据已迁移，但原启动入口因权限等原因未能更新，页面会保留警告并显示新目录中实际生成的启动文件路径。以后请使用该文件启动；刷新页面或重新打开新目录后仍可查看这条提示。普通保存成功会显示新路径，恢复此前未保存的记录时会简要提示数量。迁移失败会显示具体操作和路径，不会把未完成的迁移显示为成功。

## 存储与启动排查

任务的存储错误保留发生时的操作、路径和时间；讨论记录页可查看历史存储错误，旧记录不会被当作新任务再次失败。档案末尾未完整保存时，仍可查看此前有效记录，页面会明确提示内容不完整；已有写入失败但仍能读取的证据也会显示存储警告。

任务启动前会检查数据目录和工作目录的可用空间，运行及写入期间继续检查，并预留 **32 MiB** 用于任务收尾。空间不足时会保护性停止当前任务并保存终态；迁移到空间充足的目录后需新建任务，不会自动续跑旧任务。若其他进程突然占满磁盘，收尾写入仍可能失败，具体错误会保留以便恢复。

启动器会等待系统确认打开浏览器；默认浏览器关联失效或启动失败时，尝试已安装的 Chrome/Edge。若仍失败，会显示错误提示；也可用浏览器打开 **%LOCALAPPDATA%\discussion\打开Class.html**，点击进入工作空间。启动诊断保存在 **%LOCALAPPDATA%\discussion\startup.log**；数据目录无法写入时回退至 **%LOCALAPPDATA%\Class\logs\startup.log**。日志不包含会话令牌或模型密钥。

服务只监听 127.0.0.1，端口自动分配。启动器通过带会话令牌的链接打开界面；手动输入不含令牌的地址会提示重新打开程序。

Windows SmartScreen、安全软件或组织策略可能提示或阻止启动，不能保证每台机器均无系统拦截。遇到此类提示应核对下载来源及具体拦截原因；项目未验证全新 Windows 虚拟机上的全部安装环境。

更新时先从旧界面点击“退出服务”，确认 Class 已退出，再解压并替换 EXE 与随包许可证。用户数据不在 EXE 所在目录内，更换发布文件不会迁移或清除原配置；如曾指定其他数据目录，请继续使用原启动参数或目录选择记录。
