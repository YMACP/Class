# Agent 工具与运行控制

[返回首页](../README.md) · [调度规则](architecture.md) · [记忆工具](memory.md)

本文说明 Class 的工具能力，Windows x64 与 ARM64 构建共用这些实现。Class 在源码中实现这些工具，通过已配置的模型接口调用，不依赖 Claude Code 或 Codex 客户端来执行任务。

新增能力只扩展学生和老师的工具，不增加新的任务阶段，也不改变发现投票、老师审查、否决反馈和恢复规则。

| 工具 | 能力与用法 |
| --- | --- |
| write_file | 在工作区新建 UTF-8 文件；覆盖已有文件必须显式传 `overwrite: true`。 |
| edit_file | 使用 `path/old_text/new_text` 精确替换；默认要求唯一匹配，`replace_all: true` 替换全部。支持纯空白原文；不做模糊猜测。 |
| glob / grep | 文件名模式与内容搜索，支持分页、隐藏文件选择和明确截断说明。grep 默认字面量，`literal: false` 启用受超时控制的正则。 |
| web_search / web_fetch | 搜索公共网页、返回来源链接，或抓取网页可读正文。无需模型供应商原生搜索；公共站点的网络可达性、反机器人策略仍可能导致明确失败。web_fetch 不渲染页面，也不继承浏览器登录态。 |
| browser | 操作已安装的无头浏览器：Windows 支持 Edge、Chrome、Firefox；Linux 支持 Chrome、Firefox，也保留 Chromium。统一提供 open、navigate、tabs、snapshot、click、fill、press、scroll、screenshot、close；按成员隔离实例，暂停时冻结受管进程树，结束时清理；下载被禁用。 |
| read_image | 将 PNG、JPEG、GIF、WebP 作为真正的图片输入传给模型，单图最多 5 MiB；要求当前模型和接口支持图片。 |
| read_pdf | 提取 PDF 指定页的文字，文件最多 20 MiB，`start_page` 从 1 开始，`max_pages` 最多 20。`include_document: true` 可将完整原 PDF 传给支持 PDF 的模型，用于扫描页或图表；页码范围只限制文字提取。没有内置本地 OCR。 |
| plan_read / plan_write | 读取或更新自己的工作计划；读取可指定 `member`，或 `member: all` 查看全组。 |
| todo_read / todo_write | 读取或整体更新自己的待办；每项包含唯一 id、content、status，状态为 pending / in_progress / completed / blocked。读取可查看其他成员。 |

计划与待办是成员自报的工作记录，不是验收证明，也不会仅因标记 completed 就结束任务或解锁未修改答案的重复送审。它们在同一次运行中保留，并通过既有档案记录；新任务使用独立状态。老师可以读取全组计划和待办。

文件写入/编辑对同一路径串行处理，提交前复核文件是否变化，拒绝越界和符号链接/目录联接路径。新建文件的原子排他提交需要支持硬链接的文件系统（Windows NTFS 已验证）。搜索跳过符号链接、二进制及超过限额的内容，并明确报告扫描边界。

浏览器默认优先查找原有的 Edge/Chrome/Chromium，未找到时查找 Firefox；也可设置 `CLASS_BROWSER_EXECUTABLE` 为已安装浏览器的完整绝对路径。Firefox 要求 **149 或更新版本**，以保留阻止下载的能力；旧版会明确提示升级。Class 不内置或自动下载浏览器，本次适配不增加运行时依赖。没有可用浏览器时，仅 `browser` 调用返回明确错误，不阻止其他不需要浏览器的任务。

所有浏览器共用一套工具操作、暂停/恢复、取消和结果记录。每个成员使用独立临时配置，不接管用户已有浏览器、登录态或标签页；Linux Firefox 的临时配置位于用户主目录下的 `class-browser-*`，结束时同样清理。截图保存在工作区 `.class-artifacts/` 下并带内容哈希，老师可用 read_image 复核；这些工作区产物随工作文件保留，清理任务记录不会删掉它们。

网页搜索依次尝试 CN Bing RSS、DuckDuckGo HTML 和 Bing RSS。可用 `CLASS_WEB_SEARCH_URL` 指定包含 `{query}` 的公开搜索入口，`CLASS_WEB_SEARCH_FORMAT` 选择 `rss` 或 `html`（html 按 DuckDuckGo 结果结构解析）；自定义入口失败后仍尝试默认入口。搜索和抓取均需要本机网络能够访问目标，DNS、连接超时或反机器人拦截会明确返回错误。

三种模型协议（Messages、Responses、Chat）均将媒体作为对应的原生内容块发送。日志、工作摘要和审查快照只保存路径、大小、哈希等信息，不把大段 base64 当成文本证据。纯文本模型仍可使用 PDF 文字提取；不支持视觉/PDF 的接口不会因此自动获得视觉能力。

PDF/网络的超时按非暂停的活动时间计；PDF 解析的取消为协作式，不能当作独立进程的强制 CPU 隔离。各工具仍接入既有调用身份、结果去重、证据记录及停止控制。网页与媒体内容均属于外部数据，不是新的系统指令。
## 工具暂停的实际范围

基础读取与等待工具：read_file、list_files、sleep；配置成果档案后也提供 read_evidence，其余新增工具见上方能力清单。文件读取和目录访问限制在 cwd 内，拒绝通过符号链接访问外部路径。模型直接收到的工具输出摘要最多 64 KiB；启用运行档案时，文件读取和命令原始输出另行脱敏保存并可分页查询。截断会明确标记。读取按块暂停，sleep 按实际活动时间计时，恢复后继续剩余工作。

Windows Web UI 默认给老师和学生启用 `run_command`；老师使用独立工具执行器，在学生暂停讨论时仍可核验事实，退出时统一清理。`command` 是完整前台脚本，可包含管道和多行；`shell` 可选且只能使用工具声明中实际探测可用的执行器，`cwd` 可选且必须位于配置的工作目录内。Windows 默认使用 PowerShell。旧 `shell` 调用继续兼容，其 `command` 仍是可执行文件、`args` 是字符串数组，不按脚本解释；模型默认声明使用 `run_command`。原命令行通过 `allowShell=true` 启用命令执行，默认 false。执行器不继承模型 API key 环境变量。

工具名称和参数的明确别名可安全规范化；其他可配对的无效调用会把校验结果交回模型，在同一上下文中最多给出 3 次额外纠正机会。暂时的接口故障、不可回放的响应、截断、无效 JSON 或业务结果结构错误，会从合法上下文重试，错误调用不会执行。模型给出合法工具调用或最终回复后记为“已恢复”，也可以放弃原调用，不代表原工具已经执行。已经完成的有效调用保留结果，不因纠正或重试而重复执行；存储错误和用户停止不会被当作可恢复的模型错误吞掉。

兼容确定的工具与参数别名、单层参数包装和无关字段；重复 JSON 键、参数值或工具名称冲突会被拒绝，不会用后值覆盖前值。未支持的执行控制参数，例如 timeout、stdin、env、background 或 detached，也会明确拒绝，不静默忽略。

永久接口拒绝、输出预算或上下文无法继续、工具执行结果不确定时，可直接暂停该成员，保留上下文与证据，不虚构三次重试。执行结果不确定的操作不会自动重跑，应先检查已保存证据或工作目录中的实际结果。

同类问题会跨工具循环与回复累计诊断，重复出现时给出针对性纠正。普通文字进展、正式提交或一次格式恢复本身不会清零无进展计数；新的有效执行成果或人工重试该成员可以开启新的恢复窗口。连续同类失败且没有新进展时隔离该成员，其他成员继续。

成员的自动恢复机会耗尽后，学生会被隔离，其他可用学生继续原任务；老师失败时暂停验收，等待恢复。老师不可用或全体学生不可用时，任务保持运行并进入 `waiting_recovery`。讨论进度中的提示列出受影响成员及原因，点击“重试该成员”只恢复该成员，不重开任务；恢复成功后该成员退出列表。小组成员弹框同步显示隔离或重试状态，等待期间仍可停止和清除任务。已结束的历史任务不能重试成员。

讨论日志区分参数规范化或纠正、真实命令启动、执行成功与失败、接口重试、隔离和恢复，并显示脱敏后的实际工具名。参数校验恢复不代表命令执行成功；只有实际进程启动后才显示“已启动”，非零退出码会显示执行失败。同成员同类格式记录合并计数，展开后保留每条时间、调用标识和证据入口；可以从日志查看档案后返回。日志中的累计统计独立于近期记录裁剪，旧记录没有统计时不补造数量。运行档案中的“工具恢复记录”（`tool_validation`）保留脱敏后的原始参数、错误与轮次，日志摘要不展示原始参数。

发现、交卷、投票、合并和验收通过相应原生协作工具提交：`publish_discovery`、`submit_answer`、`vote`、`merge_discoveries`、`submit_review`。每次请求只声明该角色当前操作可用的协作工具，并保留旧 JSON 动作兼容。无需把整个回复包装成 JSON 才能发布普通进展；学生的纯文本回复作为阶段成果，同一工具回复中的公开文字也及时记入黑板，并区分学生或老师的公开进展、明确尚未核验。私有 thinking 不作为公开成果展示。正式结论仍按既有发现投票、全员审查和最终验收规则处理。

- Windows：`run_command` 按进程身份跟踪并暂停、恢复受管的前台进程树；旧 `shell` 调用仍只暂停、恢复直接子进程。
- 取消等待子进程退出；Windows 取消会终止其进程树。
- **不支持脱离运行或后台任务。** 前台进程树控制不等于任意系统进程管理；启用命令执行后不是操作系统文件权限沙箱。
- 已经发给远端模型的 HTTP 推理不能冻结服务端计算；可以取消终止，或在讨论期间缓存返回结果。文件 I/O 在检查点暂停，不能回滚已经发生的副作用。
- 暂停失败会让任务失败，而不是假装已经暂停。
