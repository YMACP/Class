# 程序更新

顶部侧栏按钮右侧显示当前程序版本。点击“更新”，Class 查询 [官方 Releases](https://github.com/YMACP/Class/releases) 的最新正式版本；不会安装预发布版本或降级。

Windows x64 匹配 `Class.exe`，Linux amd64 匹配 `Class`。下载完成后核验大小、发布页提供的 SHA256（如有）及可执行文件架构；失败不会替换现有程序。发布更高版本时，应同时上传这两个平台的可执行文件，并保持发布标签与程序内部版本一致。

确认有新版且下载成功后，Class 保存并停止本实例的任务，正常退出，再替换程序并启动。用户数据目录、启动入口和工作目录保持不变。替换或新程序启动失败时恢复旧程序并显示“更新失败”；不会结束其他 Class 实例或申请管理员权限。正在占用文件、安装目录不可写、网络或 GitHub 接口限流，都可能使更新失败。

没有更高版本时显示“当前已是最新版”。源码启动不自动覆盖 Node.js、Bun 或源码文件。更新检查只访问官方发布元数据和对应下载文件，不上传任务内容、成员密钥或历史记录。
